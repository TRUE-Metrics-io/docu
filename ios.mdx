---
title: 'iOS'
description: 'truemetrics records on Android only. There is no iOS SDK.'
---

There is no truemetrics SDK for iOS, and truemetrics does not record on iPhones or other iOS devices.

In a cross-platform app (Flutter, React Native), keep the app working on iOS as it is and guard every
truemetrics call with a platform check, so it runs on Android only and is a no-op on iOS. In Flutter:

```dart
import 'dart:io' show Platform;

if (Platform.isAndroid) {
  await sdk.startRecording();
}
```

In React Native, check `Platform.OS === 'android'`. Do not add iOS permissions or background modes for
truemetrics.

If iOS matters for your couriers, for example with a bring-your-own-device setup, contact
[info@truemetrics.io](mailto:info@truemetrics.io).
