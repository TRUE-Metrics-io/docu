## Requirements

- An Android courier app (Android 7.0, API level 24, or newer). There is no iOS SDK: see [iOS](/ios).
- Native Kotlin/Java or Flutter. React Native and Expo: see their pages and talk to us first.

## 1. Get an SDK API key

The SDK API key identifies your account; your app passes it to the SDK at initialization. Request
yours at [info@truemetrics.io](mailto:info@truemetrics.io). Which other keys exist and what they are
for is on [API keys](/api_keys).

## 3. Decide when to record

Initialize the SDK when the courier logs in, start recording when the route starts and stop it
when the route ends. The lifecycle with all its cases is on [Android Native](/android_native).

## 4. Send metadata

One event per delivery attempt, from the place in your app where the attempt reaches its final
state, with the address ID your results will be keyed by. Fields and examples: [Metadata](/metadata).

## 5. Verify

Record 30 minutes with three test events and run the check script: [Verify your integration](/verify_integration).

## 6. Get results

- [Last meter visualisation and routing](/lastmeter_routing_overview): parking place, entrance and
  walk path per address, through the API, a module or the navigation app.
- [Data export](/Architecture_of_Export): daily files in your own cloud storage or on SFTP.
