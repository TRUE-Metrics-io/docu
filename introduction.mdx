truemetrics learns the **last meter** of your deliveries: where couriers really park, which entrance
they really use and how they walk from one to the other. It learns this from your own couriers. The
truemetrics SDK records sensor data in your courier app while they deliver, your app tells it which
address each delivery was for, and truemetrics merges what it saw at each address into one parking
place and entrance per address.

## What you get

<CardGroup cols={2}>
  <Card title="Last meter in your map or navigation" icon="map-location-dot" href="/lastmeter_routing_overview">
    Parking place, entrance, waypoint, walk path and building per address: through the REST API, in
    your own map, with the truemetrics module inside your app, or in the truemetrics navigation app.
  </Card>
  <Card title="Daily data export" icon="database" href="/Architecture_of_Export">
    Parking places, entrances and stop durations (picking, walking, indoor, buffer) as files in
    your own cloud storage or on SFTP, updated every night.
  </Card>
</CardGroup>

Both start with the same step: the SDK in your courier app, sending one metadata event per
delivery attempt.

## Start here

<Steps>
  <Step title="Get an API key">
    See [API keys](/api_keys) for which key you need for what.
  </Step>
  <Step title="Integrate the SDK">
    Let a coding agent do it with the [agent prompt](/with_agent), or follow
    [Android Native](/android_native) or [Flutter](/flutter) by hand. The [Quickstart](/quickstart)
    lists the steps on one page.
  </Step>
  <Step title="Send metadata">
    One event per delivery attempt, with the address ID your results will be keyed by: [Metadata](/metadata).
  </Step>
  <Step title="Verify">
    A 30-minute test recording and a script that checks it end to end: [Verify your integration](/verify_integration).
  </Step>
  <Step title="Use the results">
    Through the [last meter API](/Lastmeter_API_Reference) or the [daily export](/Architecture_of_Export),
    once enough deliveries per address have been recorded and merged.
  </Step>
</Steps>
