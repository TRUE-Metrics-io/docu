<Info>
The base URL and your `x-api-key` are provided by your truemetrics contact. The examples below use
`https://geodata.truemetrics.cloud/V1` and `YOUR_API_KEY` as placeholders; the identifiers shown are
example address ids (the `id_address` you send as metadata).
</Info>

## A stop where entrance and parking share one identifier

The most common case: one address identifier holds both the entrance and the parking. Pass it to
**both** parameters.

<RequestExample>
```bash Example Request
curl --location 'https://geodata.truemetrics.cloud/V1/lastmetervisualization?identifier_entrance=48217063&identifier_parking=48217063' \
--header 'x-api-key: YOUR_API_KEY'
```
</RequestExample>

<Info>
When the entrance is matched to a building, a `polygon` feature (`point_type: "building"`) is also
included and drawn beneath the markers.
</Info>

<Info>
If the stop has no data yet, the call still returns `200` with an empty `features` array (and no
`raster`). This is expected — the geometry appears as soon as the stop has been processed.
</Info>

## Entrance and parking under different identifiers

If your entrance and parking live under separate address ids, pass each to its own parameter — they
are joined into one stop and connected by the dashed walking path.

<RequestExample>
```bash Example Request
curl --location 'https://geodata.truemetrics.cloud/V1/lastmetervisualization?identifier_entrance=30518472&identifier_parking=71904368' \
--header 'x-api-key: YOUR_API_KEY'
```
</RequestExample>

## Rendered image — transparent

Add `raster=true` to also receive a PNG. With no basemap the image has a **transparent**
background, so you can overlay it on your own map.

<RequestExample>
```bash Example Request
curl --location 'https://geodata.truemetrics.cloud/V1/lastmetervisualization?identifier_entrance=48217063&identifier_parking=48217063&raster=true' \
--header 'x-api-key: YOUR_API_KEY'
```
</RequestExample>

<ResponseExample>
```json Response (truncated)
{
  "type": "FeatureCollection",
  "features": [ /* … same as the first example … */ ],
```

## Toggling the building highlight and the reference point

The building footprint is drawn **by default**. Pass `building=false` to suppress it:

<RequestExample>
```bash Without the building highlight
curl --location 'https://geodata.truemetrics.cloud/V1/lastmetervisualization?identifier_entrance=48217063&identifier_parking=48217063&building=false' \
--header 'x-api-key: YOUR_API_KEY'
```
</RequestExample>

If your account sends a **reference location** with its metadata, add `reference=true` to also plot
it as a small red **taskpoint** — handy for comparing the planned location against the detected
entrance:

<RequestExample>
```bash With the reference point
curl --location 'https://geodata.truemetrics.cloud/V1/lastmetervisualization?identifier_entrance=48217063&identifier_parking=48217063&reference=true' \
--header 'x-api-key: YOUR_API_KEY'
```
</RequestExample>

```json The extra feature
{
  "type": "Feature",
  "geometry": { "type": "Point", "coordinates": [18.838450, 50.251560] },
  "properties": { "object_type": "point", "point_type": "taskpoint", "identifier": "48217063",
                  "color": "#E63946", "marker_size": 4 }
}
```

The reference point appears as a small red dot next to the detected entrance — here the planned
location sits a few metres from the entrance that was actually used:

## Saving the image on your side

The `raster.image` value is a base64 **data-URI** (`data:image/png;base64,…`). Decoding it into a
real PNG is done **on the integrating side** — your backend or your app strips the
`data:image/png;base64,` prefix and base64-decodes the rest to get the raw image bytes, which you
can then display or write to disk.

<CodeGroup>
```python Python
import base64
import requests

resp = requests.get(
    "https://geodata.truemetrics.cloud/V1/lastmetervisualization",
    params={
        "identifier_entrance": "48217063",
        "identifier_parking": "48217063",
        "raster": "true",
        "basemap": "true",
    },
    headers={"x-api-key": "YOUR_API_KEY"},
)

data_uri = resp.json()["raster"]["image"]
png_bytes = base64.b64decode(data_uri.split(",", 1)[1])

with open("lastmeter.png", "wb") as f:
    f.write(png_bytes)
```

```kotlin Android (Kotlin)
import android.graphics.BitmapFactory
import android.util.Base64
import org.json.JSONObject

// `responseBody` is the JSON string returned by the endpoint
val dataUri = JSONObject(responseBody)
    .getJSONObject("raster")
    .getString("image")

val pngBytes = Base64.decode(dataUri.substringAfter(","), Base64.DEFAULT)

// show it directly in an ImageView …
val bitmap = BitmapFactory.decodeByteArray(pngBytes, 0, pngBytes.size)
imageView.setImageBitmap(bitmap)

// … or persist it to a file
context.openFileOutput("lastmeter.png", Context.MODE_PRIVATE).use { it.write(pngBytes) }
```
</CodeGroup>
